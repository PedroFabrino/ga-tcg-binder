# ga-tcg-binder

A modern Grand Archive TCG collection and deck management application.

- Tracks physical collection at the exact **Printing** level (set edition, foil, publisher population).
- Highlights **Multi-Deck Staples**, **Low Population** collectibles, and **Idle Binder** cards.
- Manages decklists with full shortage gap analysis and explicit **Dedicated (No-Sharing)** controls.
- Detects **Friend Idle Copies** to see which playgroup friends have unassigned cards.
- Integrated **Meta Archetype Explorer** and Omnidex text importer pulling from GrandArchiveStats tournament data.
- **QR-Paired Mobile Scanner** allowing collectors to scan cards using their phone camera without logging in on mobile.
